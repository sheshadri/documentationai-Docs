## Export Playwright Tests

Export your SecuredAll scans as ready-to-run Playwright tests. These scripts replicate human-like interactions captured during scans.

<Steps>
  <Step title="Run a Scan" icon="play">
    Complete a scan in your SecuredAll workspace.
  </Step>
  <Step title="Export Tests" icon="download">
    Navigate to scan results and select `Export > Playwright`.
  </Step>
  <Step title="Run Locally" icon="terminal">
    Install Playwright and execute the generated script.
  </Step>
</Steps>

<CodeGroup tabs="Installation,Usage">
  ```bash
  npm init playwright@latest
  npm install @playwright/test
  ```
  ```javascript
  // tests/securedall-scan.spec.js
  const { test, expect } = require('@playwright/test');

  test('SecuredAll exported workflow', async ({ page }) => {
    await page.goto('https://your-app.com/login');
    await page.fill('#email', 'user@example.com');
    await page.fill('#password', 'pass123');
    await page.click('button[type=submit]');
    await expect(page).toHaveURL(/dashboard/);
  });
  ```
</CodeGroup>

## CI/CD Pipeline Setup

Integrate SecuredAll into your CI/CD workflows. Use the CLI or API to trigger scans on pull requests or deployments.

<Tabs>
  <Tab title="GitHub Actions" icon="github">
    <CodeGroup tabs="Workflow,YAML">
      ```yaml
      # .github/workflows/scan.yml
      name: SecuredAll Scan
      on: [pull_request]
      jobs:
        scan:
          runs-on: ubuntu-latest
          steps:
            - uses: actions/checkout@v4
            - name: Run SecuredAll Scan
              run: |
                npx @securedall/cli@latest scan \
                  --api-key ${{ secrets.SECUREDALL_API_KEY }} \
                  --url https://staging.your-app.com
      ```
    </CodeGroup>
  </Tab>
  <Tab title="GitLab CI" icon="git-branch">
    ```yaml
    # .gitlab-ci.yml
    securedall-scan:
      stage: test
      script:
        - curl -sSL https://cli.securedall.com/install.sh | bash
        - securedall scan --api-key $SECUREDALL_API_KEY --url $CI_ENVIRONMENT_URL
      rules:
        - if: $CI_PIPELINE_SOURCE == "merge_request_event"
    ```
  </Tab>
</Tabs>

## Webhooks for Notifications

Set up webhooks to receive scan results in real-time. Configure them in your workspace settings.

<Request tabs="Setup" show-lines="false">
  ```bash
  curl -X POST https://api.securedall.com/v1/webhooks \
    -H "Authorization: Bearer YOUR_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "url": "https://your-webhook-url.com/securedall",
      "events": ["scan.completed", "scan.failed"]
    }'
  ```
</Request>

<Response tabs="Payload">
  ```json
  {
    "event": "scan.completed",
    "scanId": "scan_abc123",
    "status": "passed",
    "issues": 0,
    "url": "https://app.securedall.com/scans/scan_abc123"
  }
  ```
</Response>

<ParamField header="Authorization" param-type="string" required="true">
  Bearer token for authentication.
</ParamField>

<ParamField body="url" param-type="string" required="true">
  Your webhook endpoint URL.
</ParamField>

<ParamField body="events" param-type="array" required="true">
  Events to subscribe to, like `["scan.completed"]`.
</ParamField>

## Third-party Tool Connections

Connect SecuredAll to popular tools for enhanced workflows.

<Expandable title="Slack Notifications" default-open="true">
  Use webhooks to post scan summaries to Slack channels.

  ```javascript
  // Example Slack webhook handler
  app.post('/securedall', (req, res) => {
    if (req.body.status === 'failed') {
      slack.chat.postMessage({
        channel: '#alerts',
        text: `SecuredAll scan failed: ${req.body.scanId}`
      });
    }
    res.sendStatus(200);
  });
  ```
</Expandable>

<Expandable title="Jira Integration">
  Create Jira issues automatically for failed scans using webhooks and Jira API.
</Expandable>
