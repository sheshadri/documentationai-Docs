## Overview

To start testing your web or mobile app with SecuredAll:

1. Sign up at `https://dashboard.securedall.com`
2. Create a new project for your application
3. Download the SecuredAll CLI tool
4. Connect your repository or upload your test scripts

## Running Your First Test

```bash
securedall run --project=my-app
```

After the test, view actionable evidence and reports on your dashboard.
