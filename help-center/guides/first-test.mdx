---
title: "Run and inspect your first test"
description: "Turn a completed scan into a small, repeatable regression check."
---

Use a single reviewed suite to learn the execution workflow before adding broad automation.

## Prepare a scan

Follow the [website quickstart](/quickstart). Wait for discovery and test generation, then confirm the expected pages appear in Overview.

If the app requires a login, verify that protected content was reached.

## Pick one meaningful suite

Open **Tests** and choose a suite for a simple, important workflow. Read the actions, input data, and expectations. Make sure the test account can complete the workflow.

## Execute and inspect

Start the suite and open **Runs**. When it completes, inspect each failed or needs-review case. Open the step evidence to understand what happened.

Fix any access or data problem before changing the application's behavior or the test expectation.

## Make it repeatable

Run the same suite again against the same environment. Once its behavior is understood, add it to a [schedule](/automation/schedules) or [CI pipeline](/automation/ci-cd).
