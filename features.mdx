AegisRunner combines app exploration, generated tests, and repeatable execution. Coverage depends on the pages, screens, accounts, and environments you make available.

| Workflow | Use it for | Start here |
| --- | --- | --- |
| Website scanning | Discover reachable pages and inspect page-level findings | [Website scans](/guides/website-scans) |
| Authenticated testing | Explore protected pages as a test user or role | [App access](/guides/authentication) |
| Native mobile testing | Explore Android and iOS test builds | [Mobile testing](/guides/mobile-testing) |
| Test suites and runs | Recheck behavior after an app change | [Test suites](/guides/test-suites) |
| Accessibility review | Investigate automated findings and download WCAG reports | [Accessibility](/guides/accessibility) |
| Baseline comparisons | Review changes against a known reference | [Baselines](/guides/baselines) |
| CI and scheduled testing | Repeat tests automatically | [Automation](/automation/ci-cd) |

## Use evidence to decide what to fix

Inspect screenshots, the failed action, expected behavior, and the environment before deciding whether a result is an application defect, an outdated expectation, or a setup problem.

The report separates behavior, accessibility, performance, security, and SEO information where available. Native mobile evidence differs from browser evidence.

## Match coverage to your app

A successful login, useful test data, and reachable workflows improve what the scanner can exercise. A page or workflow that was not reached has not been established as working.

Some workflows and quotas depend on your subscription. Check [Plans and usage](/account/plans-and-usage) for where to see your current entitlements.
