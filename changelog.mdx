For current product information, visit the [AegisRunner website](https://aegisrunner.com). For changes affecting your account or testing workflow, [contact support](/help-center).

## Check your CLI release

```bash
npm view @aegisrunner/cli version
npm list -g @aegisrunner/cli --depth=0
```

Review your automation before updating a pinned CLI version. Keep the version consistent across CI workers so a pipeline change can be reproduced.

## Track documentation changes

Documentation changes are reviewed in the [documentation repository](https://github.com/sheshadri/documentationai-Docs). The repository history describes documentation edits; it is not a product release history.
