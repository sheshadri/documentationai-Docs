## October 7 2026

Launched the Documentation.AI portal at `docs.aegisrunner.com`, with AegisRunner branding, getting-started guides, and interactive CI API reference pages.

Expanded the guides for cross-role workflows, test imports and exports, data-driven testing, browser selection, failure triage, persistence evidence, team security, SAML, and integrations. Added authenticated project and testing API reference pages and practical walkthroughs.

Old documentation topics have corresponding destinations in the new portal. Website and application documentation links are being consolidated around the new domain.

## Follow changes

Documentation edits are reviewed in the [documentation repository](https://github.com/sheshadri/documentationai-Docs). Its history tracks documentation changes and does not establish release dates for unrelated application features.

For a product change affecting your account, contact [Support](/help-center).
