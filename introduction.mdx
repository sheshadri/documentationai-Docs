AegisRunner explores websites and mobile apps, generates tests from the pages and screens it reaches, and helps you investigate failures with evidence.

Start with a scan to discover your app. Review the generated tests, then run them again after changes or from your deployment pipeline.

## Understand the workflow

| Term | What it means |
| --- | --- |
| Project | The home for an app's scans, logins, tests, runs, and settings. |
| Scan | Exploration of a website or mobile app, followed by test generation. |
| Suite | A collection of test cases, often associated with a page or workflow. |
| Test case | A sequence of actions and checks for expected behavior. |
| Run | An execution of existing tests, with a result for each case. |
| Baseline | A saved reference used to compare later results or screenshots. |

A completed scan does not mean every generated test passed in a later run. Use **Overview** for discovery results and **Runs** for execution results.
