---
title: "List project environments"
description: "Inspect configured environments before selecting an environmentId for a run."
method: GET
path: "/projects/{projectId}/environments"
---

Inspect configured environments before selecting an environmentId for a run. Keep secret values in their supported secret configuration.

Authenticate with an account session as described in [Project and testing API](/api-reference/platform-api). Use resource IDs available to the same organization and project.

For unattended pipelines, use the separately authenticated [CI endpoints](/api-reference/overview).
