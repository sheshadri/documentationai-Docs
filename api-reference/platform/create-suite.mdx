---
title: "Create a custom suite"
description: "Create a named suite with optional description, page anchor, and tags."
method: POST
path: "/projects/{projectId}/custom-suites"
---

Create a named suite with optional description, page anchor, and tags. Review any added cases before executing it.

Authenticate with an account session as described in [Project and testing API](/api-reference/platform-api). Use resource IDs available to the same organization and project.

For unattended pipelines, use the separately authenticated [CI endpoints](/api-reference/overview).
