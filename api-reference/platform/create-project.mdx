---
title: "Create a project"
description: "Create a project in an organization where the account has the necessary role."
method: POST
path: "/projects"
---

Create a project in an organization where the account has the necessary role. The website field is base_url; account creation and testing authorization are separate steps.

Authenticate with an account session as described in [Project and testing API](/api-reference/platform-api). Use resource IDs available to the same organization and project.

For unattended pipelines, use the separately authenticated [CI endpoints](/api-reference/overview).
