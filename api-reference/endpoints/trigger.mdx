---
title: "Trigger a run or scan"
description: "Start an existing test run or dispatch website or mobile discovery."
method: POST
path: "/ci/trigger"
---

Start an existing test run or dispatch website or mobile discovery. Use a CI token from the project you want to test. Acknowledging dispatch does not establish successful completion.

See [API authentication](/api-reference/authentication) for tokens and [API errors](/api-reference/errors) for completion and failure handling.
